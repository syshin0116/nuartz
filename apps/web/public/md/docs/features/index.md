# Features

> Overview of all Nuartz features for your digital garden.

Nuartz includes a rich set of features for publishing and navigating your digital garden. Here's everything available:

## Writing & Syntax

- [callouts](https://nuartz.vercel.app/docs/features/callouts) - Obsidian-style callout blocks (`> [!note]`, `> [!warning]`, etc.)
- [wikilinks](https://nuartz.vercel.app/docs/features/wikilinks) - Link between notes with `[[double brackets]]`
- [tags](https://nuartz.vercel.app/docs/features/tags) - Inline `#tags` and frontmatter tags
- [syntax-highlighting](https://nuartz.vercel.app/docs/features/syntax-highlighting) - Code blocks with dual-theme highlighting
- [latex](https://nuartz.vercel.app/docs/features/latex) - Math equations with KaTeX
- [mermaid](https://nuartz.vercel.app/docs/features/mermaid) - Diagrams and flowcharts
- [comments](https://nuartz.vercel.app/docs/features/comments) - Reader comments via Giscus (GitHub Discussions)
- [canvas](https://nuartz.vercel.app/docs/features/canvas) - Obsidian Canvas (`.canvas`) files as pannable, zoomable pages
- [bases](https://nuartz.vercel.app/docs/features/bases) - Obsidian Bases (`.base`) tables, cards, and lists built from note properties

## Navigation & Discovery

- [graph-view](https://nuartz.vercel.app/docs/features/graph-view) - Interactive graph of note connections
- [backlinks](https://nuartz.vercel.app/docs/features/backlinks) - See which pages link to the current page
- [search](https://nuartz.vercel.app/docs/features/search) - Full-text search with `Cmd+K` command palette
- [table-of-contents](https://nuartz.vercel.app/docs/features/table-of-contents) - Auto-generated heading navigation
- [breadcrumbs](https://nuartz.vercel.app/docs/features/breadcrumbs) - Path-based breadcrumb navigation
- [explorer](https://nuartz.vercel.app/docs/features/explorer) - File tree browser in the sidebar
- [folder-and-tag-listings](https://nuartz.vercel.app/docs/features/folder-and-tag-listings) - Auto-generated listing pages

## Reading Experience

- [dark-mode](https://nuartz.vercel.app/docs/features/dark-mode) - Light and dark theme with system preference detection
- [popover-previews](https://nuartz.vercel.app/docs/features/popover-previews) - Hover previews for internal links
- [reader-mode](https://nuartz.vercel.app/docs/features/reader-mode) - Distraction-free reading
- [obsidian-compatibility](https://nuartz.vercel.app/docs/features/obsidian-compatibility) - Full compatibility with Obsidian vault content

## Publishing

- [private-pages](https://nuartz.vercel.app/docs/features/private-pages) - Draft and private page support
- [rss-feed](https://nuartz.vercel.app/docs/features/rss-feed) - RSS feed generation
- [social-images](https://nuartz.vercel.app/docs/features/social-images) - Open Graph image generation
- [spa-routing](https://nuartz.vercel.app/docs/features/spa-routing) - Client-side navigation

## Planned

- [i18n](https://nuartz.vercel.app/docs/features/i18n) - Internationalization support
